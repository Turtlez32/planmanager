04 · Detailed feature specification

Describe behaviour, interaction and success

Use this module for a product feature, workflow, game mechanic or any output that needs more detail than a task card.

✦

Guided plan creation

Structured inputs become a complete, consistent plan page

Priority · High

Inputs

  • Title, owner, version and status
  • Goals, non-goals and constraints
  • Milestones, dependencies and risks

Interaction

  • Agent fetches the canonical template
  • Agent replaces examples with project content
  • Reviewer opens one self-contained HTML file

Rules

  • Keep required section order
  • Omit optional modules only when irrelevant
  • Do not redefine base layout tokens per plan

States & feedback

  • Draft, ready for review and approved
  • Risks and open questions use amber callouts
  • Completed deliverables use clear check marks
Acceptance criteria
  • The page explains what is being built, why, how and in what order.
  • Every phase has testable deliverables and every detailed feature has a success condition.
  • The layout remains readable at 360px width and when printed.
